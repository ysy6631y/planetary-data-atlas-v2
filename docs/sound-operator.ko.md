# 전시장 사운드 운영

현재 배포 화면은 카메라와 관계없이 데이터 사운드를 계속 재생하며 화면은
항상 AUTO로 순환합니다. 숫자 `1`은 사운드를 켜며, 반복해서 눌러도 화면을
멈추거나 모드를 바꾸지 않습니다. `0`은 소리만 즉시 끕니다. 배경 드론 기본
음량은 4%이며 데이터 전송음·지직거림이 중심입니다. 줌인 시작과 효과음을
동기화합니다. 상단 DATA 설정에서 배경 드론 음량을 조절할 수 있습니다.

아래 표는 개발 검토용 `?interaction=manual`에서만 쓰는 이전 동작입니다.

| 입력 | 동작 |
| --- | --- |
| 숫자 `1` | 카메라와 관계없이 AMBIENT 반복 재생, 기본 음량 15% |
| `1` 다시 입력 | AUTO로 복귀, 카메라 접근 감지에 따라 소리 재생 |
| 숫자 `0` | 배경음과 효과음을 즉시 음소거 |
| 음소거 중 `1` | AMBIENT 재생 시작 |

웹페이지에 초점이 있어야 단축키가 전달됩니다. 주소창이나 CSV 행 입력란,
음량 슬라이더 등을 편집하는 중이면 페이지 배경을 클릭한 뒤 입력하세요.
키를 길게 눌러도 모드가 반복 전환되지 않습니다.

상단 **AUDIO** 표시에서 현재 모드와 재생 상태를 확인할 수 있습니다.
표시를 클릭하면 다음 운영자 제어가 열립니다.

- **AMBIENT 시작 / 재시도**: 키 입력으로 소리가 시작되지 않을 때 클릭
- **AUTO 복귀**, **음소거**
- **AMBIENT 음량** 슬라이더: 해당 브라우저에 음량 설정 저장
- **카메라 시작 / 중지** 및 카메라 권한·접근 감지 상태

일반 모드 전환은 450ms 동안 페이드합니다. `0`은 즉시 음소거합니다.
AUTO에서 카메라 권한이 거부되거나 사람을 감지하지 못해도 `1`로 전환하면
카메라를 기다리지 않고 같은 배경음 플레이어를 반복 재생합니다.
AMBIENT에서 플레이어가 예기치 않게 일시 정지되면 같은 플레이어로 재개합니다.
`0` 음소거와 다른 탭으로 이동했을 때의 정지는 그대로 유지합니다.

헤더와 AUDIO 표시는 입력이 없으면 2.4초 뒤 숨겨지며, 마우스를 움직이면
다시 나타납니다. 운영자 설정을 열어 둔 동안에는 숨겨지지 않습니다.

Safari는 사용자 입력을 통한 재생 활성화가 필요할 수 있습니다.
키/버튼 이벤트 안에서 오디오 재생과 AudioContext 재개를 직접 호출합니다.
관련 정책은 [WebKit의 macOS 자동 재생 안내](https://webkit.org/blog/7734/auto-play-policy-changes-for-macos/)를 참고하세요.

전시장에서는 실제 iMac의 Safari 14.1.3으로 다음을 확인하세요.

1. 페이지를 연 뒤 `1`을 눌러 **AUDIO · AMBIENT / 재생 15%**와 실제 소리를 확인
2. 8초 이상 들어 반복 재생을 확인하고, 필요하면 운영자 슬라이더로 음량 조정
3. `0`으로 즉시 무음, `1`로 재개되는지 확인
4. `1`을 다시 눌러 AUTO로 복귀하고 카메라 접근 감지를 확인

**재생 차단**이면 AMBIENT 시작 버튼으로 재시도하세요. 표시가 **재생**인데
소리가 들리지 않으면 Safari 탭 음소거, iMac 출력 장치와 시스템 음량을 확인하세요.
현재 자동 검증은 Chrome과 WebKit에서 수행했으며, 전시장 Safari 14.1.3의
물리 스피커 출력까지 확인한 결과는 아닙니다.
